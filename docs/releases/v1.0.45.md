# v1.0.45 — WAF Logs transaction ID filter

Paste the transaction ID from a WAF block response into **Logs → WAF Logs → Transaction ID** to find the matching request. This release addresses [issue #47](https://github.com/socfortress/waf-platform-public/issues/47).

## What changed

- The WAF Logs table and event details display the transaction ID.
- The new filter matches the full ID case-sensitively in saved logs and the live feed. It accepts IDs pasted with surrounding whitespace. The ID appears in the block response body and the `X-WAF-Transaction-ID` header.
- Changing the filter returns saved logs to page 1 or reconnects the live feed for incoming matching events. **Clear filters** clears the transaction ID.
- This release uses the existing transaction ID index and requires no database migration.

## Images and upgrade

Production images target **linux/amd64**.

- `ghcr.io/socfortress/waf-caddy:1.0.45`
- `ghcr.io/socfortress/waf-admin-api:1.0.45`
- `ghcr.io/socfortress/waf-admin-ui:1.0.45`

Back up the database, configuration, certificate storage, and deployment settings. Preserve local Compose overrides. If upgrading from v1.0.43 or older, review the [v1.0.44 SMTP changes](https://github.com/socfortress/waf-platform-public/blob/main/docs/releases/v1.0.44.md). For v1.0.40 or older, also review the [v1.0.41 security changes](https://github.com/socfortress/waf-platform-public/blob/main/docs/releases/v1.0.41.md) and the [v1.0.40 certificate-storage migration](https://github.com/socfortress/waf-platform-public/blob/main/docs/releases/v1.0.40.md).

Update the deployment repository with `git pull --ff-only` and set both values in `.env`.

```dotenv
WAF_IMAGE_TAG=1.0.45
CRS_CADDY_DIGEST=sha256:22f786457dd6d9b6335ec8a8b997a4a874f51da8b2d78874f1cdadc1b580417e
```

The digest takes precedence over the tag. Production Caddy and the CRS validator must use the same digest. Verify the Compose configuration and upgrade the services together.

```sh
docker compose config --quiet
docker compose pull
docker compose stop admin-ui admin-api caddy-waf waf-sandbox
docker compose up -d --wait postgres redis http-echo caddy-waf waf-sandbox
docker compose up -d --wait admin-api admin-ui
docker compose ps
```

After upgrading, check **About → Version** shows v1.0.45. In WAF Logs, copy a transaction ID from an event's details, paste it into the filter, and verify that the matching event appears. Existing installations with update checks enabled discover the release on their next cached check (up to 6 hours).
